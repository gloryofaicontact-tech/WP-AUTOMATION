# WP-Automation MCP Server

A Model Context Protocol (MCP) server that lets **Claude Desktop**, **ChatGPT Custom GPTs**, and **Gemini** send articles directly to your WordPress sites via the WP-Automation backend — no copy-pasting needed.

## Tools Provided

| Tool | Description |
|------|-------------|
| `list_my_websites` | List all your connected WordPress sites |
| `get_content_types` | Get available post types for a site |
| `list_articles` | Browse your draft and published articles |
| `send_article_to_backend` | Send raw text → AI structures it → Envato images → WordPress draft |
| `publish_article` | Publish / unpublish / delete an article |

## Setup

### 1. Install & Build

```bash
cd mcp-server
npm install
npm run build
```

### 2. Get a JWT Token

```bash
curl -X POST http://localhost:3000/api/v1/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"editor@example.com","password":"YourPassword"}'
```

Copy the `accessToken` from the response.

### 3. Configure Claude Desktop

Edit `%APPDATA%\Claude\claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "wp-automation": {
      "command": "node",
      "args": [
        "C:\\Users\\weblook\\Desktop\\Project\\WP-AUTOMATION\\mcp-server\\dist\\index.js"
      ],
      "env": {
        "WP_BACKEND_URL": "http://localhost:3000/api/v1",
        "WP_BACKEND_TOKEN": "YOUR_JWT_TOKEN_HERE"
      }
    }
  }
}
```

Then **restart Claude Desktop**. You'll see the 🔧 tools icon in the chat.

### 4. Example Claude Workflow

```
You: List my websites
Claude: [calls list_my_websites] → shows site list with IDs

You: What content types does site e47912d6... have?
Claude: [calls get_content_types] → post, tour-package, destination

You: Here's my article about Bali tours: [paste text]
      Send it as a tour-package to that site and auto-publish it.
Claude: [calls send_article_to_backend with autoPublish=true]
        → AI structures it, finds Envato images, publishes to WP
```

## For ChatGPT Custom GPTs

Use the OpenAPI spec auto-generated by NestJS Swagger:
- `http://localhost:3000/api/v1/docs-json` → import as a GPT Action
- Set Auth: `Bearer Token` → paste JWT

## For Gemini

Declare the same 5 tools using Gemini Function Calling JSON schema format and call your backend API endpoints directly.
